# Your finished videos

When you approve a version of a video, it is copied here, inside a folder for its project and named after the video (for example `my-project/my-video.mp4`). These are the files to post or share.

A video with more than one version keeps its name and adds the shape, so the versions sit together: `my-video-vertical.mp4` (or `-square`) for social, `my-video-youtube.mp4` (16:9) for YouTube. YouTube treats vertical and square videos under 3 minutes as Shorts, which is why the YouTube version is separate.

Every earlier version is still kept in `workspace/projects/<project>/<video>/drafts/`.

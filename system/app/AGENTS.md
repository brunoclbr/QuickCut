# Companion app instructions
Read README.md here before modifying the app. Keep the AI app (Codex or the user's AI app of choice) as the primary interface. This browser app is a read-only companion: it shows state and where files are, and offers copyable instructions for the AI app. Never add actions that change anything — no file writes, folder creation, approvals, uploads, command execution, rendering, embedded AI, cloud deployment or duplicated preference storage. Editing-factor selections build instructions only. The one owner-approved exception is the ElevenLabs key (connect, change, disconnect via `system/voiceover/service.mjs`), so secrets never pass through the AI app; do not add other exceptions.

Functional code stays in this folder. Preserve GET/HEAD-only access (plus the two same-origin ElevenLabs key endpoints), bounded localhost access, path/symlink checks and plain-text-safe rendering when customizing. Run `npm --prefix system/app test` from the repo root after changes. Tests must use temporary fixture workspaces; never trigger video renders or modify real preferences for automated tests.

# My editing process
1. Read AGENTS.md, workspace/preferences/editing-guide.md, workspace/preferences/editing-rules.md, the asset index, system/assets/editorial/RECIPES.md (the Editorial Motion Toolkit, which has priority for supporting visuals, callouts, transitions and sound cues) and this video's brief and feedback.
2. Inspect the existing setup. If missing, follow https://github.com/heygen-com/hyperframes to install the core HyperFrames skills and required media tools. Verify with a short playable test and record tool versions and paths in system/setup/setup-notes.md. Do not claim these instruction files install the tools.
3. Inspect the selected source take and transcript. Flag missing footage, fonts, references or sounds. Never silently substitute assets.
4. Produce a numbered 15-second opening draft from the real footage. Keep my meaning, voice and face intact. Apply my guide; ask about unfilled decisions that materially affect the result.
5. Take timestamped feedback. Preserve approved elements and original files. Show revised sections, then extend the approved treatment to the full video.
6. Check the actual output end to end: captions, fonts, framing, supporting visuals, sound, cuts, final CTA, dimensions and playback.
7. When asked, update the guide with lasting decisions and the rules with concise reusable lessons. Remove conflicting superseded guidance; keep one-off changes with this video's feedback. Report exactly what was saved.
8. Begin the next video in this project by reading the saved files again.

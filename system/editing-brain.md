# My editing process
1. Read AGENTS.md, workspace/preferences/editing-guide.md, workspace/preferences/editing-rules.md, the asset index, system/production-lessons.md (how to build and check HDR compositions without repeating past errors), system/assets/editorial/RECIPES.md (the Editorial Motion Toolkit, which has priority for supporting visuals, callouts, transitions and sound cues) and this video's brief and feedback.
2. Inspect the existing setup. If missing, follow https://github.com/heygen-com/hyperframes to install the core HyperFrames skills and required media tools. Verify with a short playable test and record tool versions and paths in system/setup/setup-notes.md. Do not claim these instruction files install the tools.
3. Inspect the selected source take and transcript. Flag missing footage, fonts, references or sounds. Never silently substitute assets.
4. Visual calibration (unless I say to reuse the last baseline): make three 5–10-second samples from the same footage, Minimal, Editorial and Dynamic editorial, as described in my guide. Save them as `drafts/sample-a-minimal.mp4`, `drafts/sample-b-editorial.mp4` and `drafts/sample-c-dynamic-editorial.mp4` so the companion shows them, and record my pick in this video's feedback.md as its visual baseline.
5. Produce a numbered 15-second opening draft from the real footage. Keep my meaning, voice and face intact. Apply my guide; ask about unfilled decisions that materially affect the result. Build it from a script anchored to spoken words, starting from the approved reference build (system/production-lessons.md).
6. Take timestamped feedback. Preserve approved elements and original files. Show revised sections, then extend the approved treatment to the full video. When the opening changes, render only its first ~10–12 s for approval before the full render. When feedback is long or ambiguous, say what you understood and ask before editing.
7. Check the actual output end to end: captions, fonts, framing, supporting visuals, sound, cuts, final CTA, dimensions and playback, using the checks in system/production-lessons.md (decode, loudness, transcript around every change, contact sheet, lips never moving without sound). Ship the voice + effects WAV next to each draft. Then run the editorial quality check before presenting any draft:
   1. Does it look like one coherent, deliberately designed piece rather than a collection of templates?
   2. Are any coloured boxes, animated elements or graphics unnecessary?
   3. Does the footage remain the main focal point?
   4. Is the typography consistent?
   5. Is it engaging because the storytelling works, not because everything moves?
   6. Would removing an effect make it cleaner without reducing comprehension?
   7. Are my voice, appearance, delivery and meaning preserved?
   If an element grabs attention but adds no information or meaningful emphasis, simplify it.
8. When asked, update the guide with lasting decisions and the rules with concise reusable lessons. Remove conflicting superseded guidance; keep one-off changes with this video's feedback. Report exactly what was saved.
9. Begin the next video in this project by reading the saved files again.

# Copy-and-paste editing prompts

## check my folder

I don’t know how to code. This is my video-editing project. Read AGENTS.md, system/editing-brain.md, workspace/preferences/editing-guide.md and workspace/preferences/editing-rules.md. Tell me which files you found and what needs to be filled in. Keep this folder as the home for my editing setup. Explain technical decisions in plain English.

## set up the video tools

Read my system/editing-brain.md and the official setup at https://github.com/heygen-com/hyperframes. Inspect this project before changing anything. Install the core HyperFrames skills for this environment using the current official instructions. Set up the media tools needed to inspect, transcribe, edit and export my footage, including FFmpeg if needed. Use a small source clip I supply to create a short playable MP4 test. Save the working setup and versions in system/setup/setup-notes.md. Tell me what is ready and what still needs my input. Don’t call setup complete until the test plays.

## interview me and build my guide

Help me fill in workspace/preferences/editing-guide.md. Interview me in small batches about my audience, reference edits, title and caption fonts, font files, capitalization, text size and placement, colors, pacing, transitions, supporting clips, music and sound effects. Ask what I dislike as well as what I like. If I can’t name a style, help me describe it from my reference. Save my answers in workspace/preferences/editing-guide.md, show me a short summary, and list any missing files. Keep this separate from the brief for one particular video.

## turn my assets into a usable library

Look at the font, sound and supporting-media files I added. Create a workspace/assets/asset-index.md with the exact filenames, what each is for and anything missing. Ask me which sound belongs to each kind of visual event. Do not guess a paid font or replace a missing asset without telling me. Reference this index from workspace/preferences/editing-guide.md.

## start the next video with my saved style

Before editing, read AGENTS.md, system/editing-brain.md, workspace/preferences/editing-guide.md, workspace/preferences/editing-rules.md, workspace/assets/asset-index.md if present, and this video’s brief. List the files you read and summarize the current font, caption, sound and framing rules. If a file is missing or inaccessible, tell me before rendering. Reuse the working setup in system/setup/setup-notes.md.

## create my first draft

Read my saved editing files and workspace/projects/<project>/<video>/brief.md. Inspect the footage and identify the take and transcript you’ll use. Create a 15-second opening draft using my reference, font files and approved supporting media. Keep my real voice, meaning and face unchanged. Give me a playable MP4, not just an edit plan, and tell me which choices need my review. Number the draft and preserve the source.

## apply a feedback round

Update draft [filename]. At [timestamp], change [specific thing] to [desired result]. Keep [approved elements] unchanged. Record these notes in this video’s feedback.md, save a new numbered draft and show me the changed section. If the change affects other timings, explain that before applying it across the full video.

## update my guide with what we learned

Review the feedback rounds and the version I approved. Update workspace/preferences/editing-guide.md with the lasting preferences I explicitly chose, and update workspace/preferences/editing-rules.md with the reusable lessons, date and a brief example. Remove or revise outdated guidance that these decisions replace; don’t add duplicates. Keep one-off timestamps and clip choices in this video’s feedback.md. If a preference is unclear or conflicts with another rule, ask me about that point. Show me what changed and the files you saved. Read the updated guide before the next edit.
